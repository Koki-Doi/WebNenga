# Web年賀状（ローカル版）

ブラウザだけで宛名面・挨拶面を編集し、そのまま印刷まで完結できるシングルページアプリです。ビルド不要で `index.html` を静的サーバーで開くだけで動作します。

## 使い方
- 左下「編集」を押すとエディタが開きます。PCでは右側のドックパネル、モバイルでは下部シートとして開き、**カードを見ながら**編集できます。
- 宛名・敬称・差出人・挨拶文・背景を入力／選択すると即時プレビューに反映されます。編集中の項目に応じてカードの表裏が自動で切り替わり、カードをタップして手動で反転することもできます。
- エディタは「×」ボタンまたは Esc キーで閉じます。
- 右下の「印刷」ボタン（PCのみ）から印刷プレビューを開きます。モバイルはブラウザ標準の印刷から出力してください。
- カードはクリック / Enter / Space / 左右スワイプで裏表反転します。
- ジャイロによる傾き操作は、タッチ対応のiPhone・iPad・Androidで端末方向APIが利用できる場合に有効です。許可が必要なブラウザでは「Gyroを有効化」を表示し、許可後に消えます。PC（タッチ対応Windowsを含む）ではボタンを表示せず、マウスで傾きを操作します。

## 主な機能
- 宛名面と挨拶面のリアルタイム編集・プレビュー
- 背景画像のサンプル適用・任意画像アップロード（Cropper.jsで100:148にトリミング）
- 挨拶文メッセージの自動フィット（PCでの改行位置をモバイルでも維持）
- 画像／メッセージ縦位置の微調整（ローカルに保存）
- CSV一括モードで宛名リストから共有URLを生成
- **年賀状ガチャ演出（ウマ娘パロディ・2027）**: 共有リンクで開いた閲覧者が「タップして裏面を見る」を押すと、突然ガチャ演出が始まり、SSR確定（★3）として年賀状の裏面が排出されるジョーク機能

## 年賀状ガチャ演出について
- 発動条件: `#id=…&data=…` 付きの共有リンクで開き、宛名面を初回タップしたとき（エディタ表示中・2回目以降は通常のフリップ）
- 流れ: 扇子「激熱ッ！」→ 赤い廊下を年賀ハガキが舞い赤茶の両開き扉へ → 扉開放 → ペンライトの観客席 → スタートゲート全景 → 枠番パン（1番=金 →10番=虹） → 発走ランプ点灯 → 虹ゲートから発走（ハガキ疾走） → セリフ → SSR確定演出（実データの裏面が名前帯・★3付きで登場） → タップで本物の裏面へ
- ハガキの表裏は画面の実カードから作る。両面とも、画面の実レイアウトを1文字ずつ測って canvas へ描く（`js/print.js` の `renderAddressFaceCanvas` / `renderGreetingFaceCanvas`）。html2canvas は文書を複製して組み直すため、縦書き・`cqh` 単位・挨拶文の改行位置が画面と変わることがあり、演出では使わない（印刷機能だけが使う）。宛名面は開演時、挨拶面はセリフ画面の間に作り、確定画面は完了を待つ（失敗時は手描きの予備を表示）
- 初回描画の引っかかりを避けるため、シェーダのコンパイルとテクスチャ転送は先読み中に済ませる（`prewarm`）。ゲートは全景では全房とも鉄色で、横パンで光った瞬間に金・虹へ変わる
- 無効化: URLに `?nogacha` を付ける（例: `…/?nogacha#id=…`）
- デバッグ: `?gphase=フェーズ名` で任意フェーズから自動再生（fan / dash / doorOpen / crowd / sky / whiteflash / gateWide / gatePass / lamp / goldGate / run / speech / reveal）
- 実装: `js/gacha/`（three.js + gsap を CDN の import map で解決、ビルド不要）と `gacha.css`。エンジンは共有リンク閲覧時のみアイドル時間に遅延ロード
  - `race-art.js`: ゲート扉・番号札・鋳鉄飾り・雲・芝などを canvas に描く関数群（原作の録画 `movie/frames` を見て描き起こした絵。画像ファイルは持たない）
  - `gacha-fx.js`: ゲート通過時の光の粒・発走のスピード線・年賀状のきらめき軌跡（いずれも 1 draw call）
  - 造形の確認は `model-preview.html`、カメラの連続性は `node --test tests/*.mjs`
- 本演出はウマ娘のガチャ演出のファンメイド・パロディです（Cygames とは無関係。画面内への注釈表示はなし）

## Google Analytics（カード単位の計測）

現行仕様と管理画面での確認事項は [GA4実装・検証記録](docs/ga4-implementation.md) を参照してください。

- 宛名（recipient）・差出人（sender）・本文（message）を独自イベントへ送り、エラー時は生のメッセージ（error_message）も送ります。旧ユーザープロパティは解除し、カード情報はイベント単位で扱います。
- `card_view`（表示）、`card_flip_to_back`（初回裏面）、`card_leave`（表示時間と反転回数の差分）、`js_error`（定型コードと生エラーメッセージ）を計測します。
- ガチャは `gacha_start/gacha_skip/gacha_complete/gacha_error`。`gacha_complete.completion_reason` で `completed/skipped/error` を区別します。
- カード切替時は旧カードの時間を確定し、新カードの計測を開始します。素のエディタが共有URLを生成しただけではcard_viewを開始しません。
- 作成者判定は端末内履歴からの推定。`?as=creator` / `?as=recipient` で明示指定を保存し、`?as=auto` で履歴ベースへ戻せます。
- localhost・127.0.0.1・IPv6ループバック・非HTTP(S)ではGAタグを読み込まず、独自イベントも送信しません。
- 送信するページURLからクエリとフラグメントを除き、リファラーは空にしています。通常のpage_viewは本番のconfig時に送信します。GA4管理側の拡張計測・実データ受信は別途確認が必要です。

既存カードIDは互換性のため維持しています。宛名・差出人由来のID設計、過去に送信済みの氏名データ、GA4管理側の設定は今回のコード修正では変更していません。

本文とエラーメッセージはアプリ側では切り詰めず送信関数へ渡します。GA4側での受信・全文保存は未確認です。ローカルテストの成功と本番での受信確認は区別してください。

## ファイル構成
- `index.html` : 画面本体とエディタUI
- `nenga.css` : レイアウト、3Dカード表現、印刷スタイル
- `js/`  
  - `main.js` : 初期化エントリ  
  - `card-controls.js` : 裏表反転・操作入力  
  - `card-effects.js` : パララックス・光沢・ジャイロ  
  - `editor.js` : 入力反映・共有URL生成・背景アップロード・CSVモード  
  - `position-controls.js` : 画像/挨拶文の縦位置調整  
  - `message-autofit-lite.js` : 挨拶文の自動フィット（軽量版）  
  - `print.js` : 画面を画像化して印刷（宛名縦積みなどの前処理を含む）  
  - `image-utils.js`, `storage.js`, `templates.js`, `utils.js`, `csv-mode.js` ほか補助スクリプト

## 開発メモ
- **模型室**: `model-preview.html` を同じ静的サーバーで開くと、扇子・廊下の扉・ゲート・観客席・コース・サンプル年賀状を回転／拡大して確認できます。カメラ演出の実時間再生とコマ送り、扉の開閉、ワイヤーフレーム、視点リセットに対応。実際の共有カードは読み込みません。
- **回帰確認**: Node.js で `node --test tests/*.test.mjs`（2026-09-27時点で34件）。3D形状は別途、静的サーバー上の `tests/model-geometry.html` で10項目を確認できます（Three.jsのCDN接続が必要）。
- 現行コード全体とGA4の調査は [`docs/code-audit.md`](docs/code-audit.md)、性能・ジャイロの変更履歴は [`docs/performance-review.md`](docs/performance-review.md) を参照してください。
- モデリング改善と調査記録は [`docs/project-review.md`](docs/project-review.md) を参照してください。
- ビルドレス構成です。編集後はブラウザをリロードするだけで反映されます。
- 共有URL機能や外部ストレージ連携は`storage.js`などに設定があります（必要に応じて差し替えてください）。
- 印刷はhtml2canvasでDOMを画像化して2ページ（挨拶面/宛名面）を生成しています。

## 印刷のポイント
- PC：右下の「印刷」ボタンを使用。ブラウザの印刷設定で「背景のグラフィック」を有効にしてください。
- モバイル：ブラウザ標準の印刷機能から出力してください（表示と同じ幅でキャプチャします）。
- 宛名面は横書きテキストを`<br>`で縦積みし、スペースは空行として扱います。
